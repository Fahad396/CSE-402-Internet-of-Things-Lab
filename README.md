# CSE-402-Internet-of-Things-Lab
A collection of lab experiments, projects, and implementations for **CSE 402: Internet of Things Lab**. This repository covers IoT concepts, sensors, microcontrollers, communication protocols, and practical IoT applications.
This repository contains lab experiments, assignments, and projects for **CSE 402: Internet of Things Lab**.

## 📌 About

The lab focuses on practical implementation of Internet of Things (IoT) concepts using sensors, microcontrollers, communication protocols, and connected devices.

## 🧪 Lab Topics

* Introduction to IoT and embedded systems
* Sensors and actuators
* Arduino and microcontroller programming
* ESP8266/ESP32-based IoT applications
* Wi-Fi and wireless communication
* MQTT and other IoT communication protocols
* Cloud-based IoT applications
* Data collection and monitoring
* Practical IoT projects
